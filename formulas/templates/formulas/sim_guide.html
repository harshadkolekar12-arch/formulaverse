Written reference
🖥️ The main view

The largest area on screen is where the physics actually happens — a container, a circuit, a wave, a ray diagram. Watch this area after every change you make; it updates in real time, it doesn't need a "run" button for most sims.

🎛️ The control panel

Usually along one side or the bottom. Three kinds of controls show up again and again:

  • Sliders — drag the handle, or click a spot on the track, to change a value like mass, speed, or resistance.
  • Checkboxes — turn on-screen extras on or off: vectors, labels, grid lines, rulers.
  • Dropdowns / radio buttons — switch between scenarios or modes, like changing the fluid or the type of block.
✋ Direct interaction

Many objects in the main view are draggable — try clicking and dragging blocks, charges, or markers directly instead of only using the side panel. If something looks like an object in the world rather than a button, it's probably draggable.

💡 Try this
  1. Change one control at a time and watch what happens in the main view before you touch anything else.
  2. Read the on-screen numbers as you change that one variable — does it match what the formula predicts?
  3. Hit reset and repeat with a different variable, so you can isolate what each one actually does.
